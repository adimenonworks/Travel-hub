# Rove feel and native: navigation, gestures, sheets, the iPhone shell

**Read this before changing how the app moves or behaves:** navigation and screen transitions, Bottom navigation, gestures, scrolling, the keyboard, sheets, loading, haptics, or the native iPhone code in `ios/`.

**Moved word for word from `CLAUDE.md` on 14 Nov 2026,** when it was split (see `docs/DECISIONS.md`). Keep it current: when the app changes, update this file in the same pull request. If it disagrees with the code, Figma or `CLAUDE.md`, say so and fix whichever is wrong.

- **Bottom navigation** (Figma "Bottom navigation" + ".Navigation item"; `BottomNavigation` in `src/design/components`): Home (`/`: greeting, your upcoming trip, What's next, Banners), Trips (`/trips`: Your trips; also lit on a trip's pages) and You (`/profile`). It is 60px tall and floats 18px from the sides and 24px from the physical bottom edge, like Wise (no safe area under it), always on top; content scrolls under it (every page's 96px bottom padding clears it, plus the safe area). The selected pill slides between tabs, and can be dragged along the bar like iOS (it follows the finger, a selection tick as it crosses each tab; the bar is `touch-action: none`, so once dragging it keeps hold wherever the thumb wanders until it lifts, and letting go, or iOS cancelling the touch, snaps to the nearest tab); taps have no haptic; tapping the current tab scrolls to the top. Shown on every signed-in page except Join and Design; hidden while the keyboard is open.
- **Navigation** (`src/app/navigation.ts`, `src/app/ScreenStack.tsx`): both screens move together, like iOS (owner, 11 Nov 2026: "planted, smooth, premium"). Opening something slides the new screen in from the right (soft edge shadow) over the old one, which drifts 30% left and dims; back buttons (`PageHeader` back) step back through history (`goBack`) and do the mirror (the current screen slides off to the right, the previous one comes in from the left at its saved scroll position); Bottom navigation taps cross-fade (the old tab fades out over the new one, never a blank frame) and return to that tab's own scroll position. `ScreenStack` notices the change while rendering, so the leaving screen stays mounted (nothing rebuilds) and is pinned where it was in a fixed, inert layer; the slide is held on its first frame until the new screen has drawn (two animation frames), then runs on transform and opacity only; Reduce Motion: a short fade. Scrolling has the iPhone's native rubber-band bounce at the top and bottom of every page, short pages included: Capacitor turns the web view's bounce off natively (`scrollView.bounces = false` in its own setup), so `RoveViewController.capacitorDidLoad` turns it back on (`bounces`, `alwaysBounceVertical`; never sideways), and the CSS has no `overscroll-behavior: none` on the page (sheets and the New trip flow use `contain`). There's no pull-to-refresh: trip data comes from live Firestore listeners (changes arrive within a second and catch up when the app returns), and flight status re-checks when you come back to the app. Presses: cards and Event cards scale to 0.97 at once and spring back (`--motion-release`); big cards (Hero card, Card) 0.98; rows in a List group highlight instantly and fade out on release, like iOS. Swipe back from the left edge is ours (`src/app/SwipeBack.tsx`): it draws the real previous screen underneath at its scroll position and follows the finger; the web view's own swipe is off (`allowsBackForwardNavigationGestures = false`). The status-bar strip is always the page colour, so nothing shows through behind the clock. A trip's tabs are one screen (the header stays; the tab panel slides, see App structure); switching tabs replaces the history entry (`Tabs replace`, and the tab swipe), so Back leaves the trip in one step. Each screen's scroll position is restored on back. Data hooks (`src/data/hooks.tsx`) keep the last value of every listener for the session, so a screen that opens again shows its data at once instead of flashing a skeleton.
- **Nothing drags or previews:** links, images and maps can't be dragged out or long-pressed for a preview (`-webkit-user-drag` / `-webkit-touch-callout` in base.css; `allowsLinkPreview = false` and drag interactions off in `RoveViewController`), and only fields and `.selectable` text can be selected.
- **Keyboard:** iOS's accessory bar (‹ › Done) shows above the keyboard (`setAccessoryBarVisible` in `setupNative()`); Done collapses it.
- **Sheets** slide up and close by dragging their top down. The app doesn't resize for the keyboard (`resize: 'none'` in `capacitor.config.ts`): `setupNative()` puts the keyboard's height in `--keyboard-height`, a sheet focuses its first field as it opens (the polish prompt reverses this) and rises with the keyboard as one (CSS `translate`, the keyboard's timing).
- **Loading:** `PageSkeleton` / `Skeleton` (Figma "Skeleton": text lines are pills, blocks 24px corners, circles; the start-up skeleton, drawn before the app frame, is `PageSkeleton fullscreen` so it clears the status bar and Dynamic Island), never a spinner (the one exception, from Figma: "Create my trip" turns into a spinner on the button, `Button loading`, before the flood). The app opens from the on-device cache (Firestore offline cache, cached profile) before the server answers.
- **Native (iPhone app):** `RoveViewController` (in `ios/App/App/AppDelegate.swift`; `SceneDelegate.swift` makes it the root screen, and hands Google sign-in return links to `GIDSignIn`) turns on swipe-back and sets the light/dark canvas colour (white / #1c1c1c, the page colour) so nothing flashes white; the launch screen has a dark version. `setupNative()` in `src/lib/native.ts` keeps the status bar and keyboard in the app's theme, passes the keyboard height to CSS and hides the tab bar while typing. Sharing uses `shareLink()` (native share sheet). The share extension target (`ios/App/ShareExtension`, bundle `com.adimenon.rove.share`) opens `rove://save?url=…` (URL scheme in Info.plist; `@capacitor/app` delivers it) and copies the link instead if Rove can't be opened. Invite links use `PUBLIC_SITE` in the app (the app's own address is `capacitor://localhost`).
